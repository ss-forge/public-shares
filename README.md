* **Three-Tiered Physical Hardware Profiles:**

  * **PicoDC Edge Nodes (2U Enterprise/Tactical):** Liquid/air-cooled units enabling 100% offline continuous reasoning inside enterprise server rooms.
  * **PicoDC Endpoint Nodes (Small Form Factor):** Ultra-low-wattage micro supercomputers executing autonomous agents and local inference at the extreme edge.
